Base color alpha

For MW2019 / MW2022 / IW colour images: the alpha is metalness (up to 10% it's the non-metal reflectance), split exactly like GameImageUtil's "CoD Specular/Albedo (IW/MW)". The Metallic slot isn't needed. Use a PNG: convert the DDS with GameImageUtil's "Direct Convert" mode first.

Metal keeps diffuse
25%

Physically metal has no diffuse colour, but SMap only has a grey shine value and a dim reflection, so fully black metal shows as black patches. Tarkov's own metal is dark grey; 20 to 35% keeps it looking like metal.

Diffuse brightness
255

Lower the number to brighten. Tarkov blacks should be dark grey, not pure black.

Specular on non-metal
56

56 (#383838) is a starting point. Fine-tune in Unity against a base-game item.

AO
100%

Only for real AO: soft shading in creases. Leave off if it's hard shapes or speckles.
